### 1. Ransomware Detection and Response System (RDRS)

A defensive cybersecurity project designed to monitor suspicious file-system and process activities and identify potential ransomware-like behavior.

**Key Features:**
- Real-time file activity monitoring.
- File entropy analysis to help identify suspicious file modifications.
- Process metadata collection.
- Threat scoring and security alerts.
- SQLite-based event and incident tracking.
- Quarantine simulation and incident evidence handling.
- REST API and dashboard integration.

**Technologies:** Python, Watchdog, psutil, SQLite, REST API
